Kebijakan Privasi.

Terakhir diperbarui: September 2026.

Data yang kami proses

File yang Anda upload diteruskan oleh server kami ke Catbox.moe untuk dihosting. Server kami tidak menyimpan isi file setelah upload selesai. File sementara dihapus otomatis.

Riwayat di perangkat Anda

Riwayat link upload disimpan di localStorage browser Anda sendiri, bukan di server kami. Menghapus riwayat atau data browser akan menghilangkannya.

Pihak ketiga

File yang diupload tunduk pada kebijakan Catbox.moe sebagai penyedia hosting. Kami tidak membagikan data Anda ke pihak lain untuk iklan atau pelacakan.

Keamanan

Kami membatasi ukuran file, memblokir ekstensi berbahaya, dan memakai koneksi terenkripsi. Meski begitu, jangan upload data sangat sensitif karena link bersifat publik bagi siapa pun yang memilikinya.

Kontak

Pertanyaan soal privasi dapat disampaikan melalui kanal resmi tempat aplikasi ini dipublikasikan.
