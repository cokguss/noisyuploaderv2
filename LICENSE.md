## BAGIAN II: KETENTUAN LAYANAN & PENGGUNAAN (TERMS OF SERVICE)

### Pasal 4: Kepatuhan Terhadap Platform Pihak Ketiga
1. Noisy Uploader V2 beroperasi dengan berinteraksi pada layanan dan Application Programming Interface (API) pihak ketiga (Catbox.moe sebagai penyedia hosting file, serta layanan pendukung terkait).
2. Pengguna memahami sepenuhnya bahwa setiap platform memiliki Ketentuan Layanan masing-masing, termasuk aturan hak cipta dan konten yang diperbolehkan.
3. Segala akibat dari penggunaan Noisy Uploader V2 — termasuk namun tidak terbatas pada penghapusan file oleh Catbox, klaim hak cipta atas konten yang diunggah, atau pelanggaran ketentuan platform — adalah **tanggung jawab penuh Pengguna**. cokguss tidak bertanggung jawab atas kerugian tersebut.
4. Pengguna wajib menghormati hak cipta dan hanya mengunggah file yang dimiliki atau diizinkan pemiliknya.

### Pasal 5: Ketersediaan Layanan & API Pihak Ketiga
1. Noisy Uploader V2 disediakan secara **gratis** tanpa skema berlangganan dan tanpa registrasi akun.
2. Noisy Uploader V2 bergantung pada API pihak ketiga (Catbox.moe) yang dapat berubah, membatasi, atau berhenti sewaktu-waktu di luar kendali cokguss. Kegagalan fungsi upload akibat perubahan pihak ketiga bukan merupakan cacat produk maupun kewajiban ganti rugi.
3. Kepermanenan link mengikuti kebijakan Catbox.moe; Noisy Uploader V2 tidak menjamin file tersimpan selamanya dan dapat menghapus akses bila ada penyalahgunaan.

### Pasal 6: Privasi Data
1. Noisy Uploader V2 tidak meminta registrasi akun dan tidak mengumpulkan data pribadi Pengguna.
2. Riwayat upload disimpan secara lokal di peramban Pengguna (localStorage) dan tidak dikirim ke server mana pun.
3. Server hanya meneruskan file ke Catbox dan tidak menyimpan isi file setelah proses selesai; file sementara dihapus otomatis.
4. Demi keamanan, file executable (.exe, .bat, .cmd, .msi, .scr, .ps1, .com, .pif) diblokir otomatis dan file di atas 200MB ditolak.
